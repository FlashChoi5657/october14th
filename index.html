rclone personal Drive client

This is a private, single-user OAuth client used by the site owner to mount their own Google Drive on their own server with rclone, an open-source file sync tool.

It is not a public service. It is not offered to other users, and it has no sign-up, no web interface, and no other users.

What it accesses

Only the owner's Google Drive files, so they can be read and written from the owner's server. Data goes directly between Google Drive and that server.

See the Privacy Policy.
