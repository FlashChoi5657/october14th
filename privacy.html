Privacy Policy — rclone personal Drive client

Last updated: 2026-10-14

This OAuth client is used only by its owner to access the owner's own Google Drive with rclone. It is not offered to anyone else.

Data accessed

Google Drive files and file metadata in the owner's account, using the scopes the owner grants during sign-in.

How data is used

The data is used only to sync and mount the owner's files on the owner's own server. Data goes directly between Google's servers and that server.

Sharing and storage

No data is sent to, sold to, or shared with any third party. No analytics or advertising is used. The OAuth token is stored only on the owner's server and can be revoked at any time at myaccount.google.com/permissions.

Google API Services User Data Policy

Use of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements.
